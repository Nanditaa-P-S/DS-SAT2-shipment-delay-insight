# CH23 Shipment Delay Insight — Synthetic Practice Dataset

Files:
- shipments.csv: shipment, origin/destination, dispatch, promised/actual delivery dates, carrier, service level, shipment type, route/weather/hub IDs
- routes.csv: route distance, route type, number of hubs
- carriers.csv: carrier names and metadata
- events.csv: hub arrival/departure, exception codes, transit duration
- weather.csv: rainfall, visibility, storm flag

Some data-quality issues are intentionally included for cleaning practice: missing delivery dates, duplicate shipment records/IDs, inconsistent route names, incomplete exception codes, and invalid transit durations.
